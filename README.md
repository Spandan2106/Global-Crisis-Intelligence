# Global Crisis Intelligence

An interactive platform designed for monitoring global conflicts, crises, markets, and geopolitical developments in real-time. 

## 🚀 Features

*   **Tactical HUD:** Advanced heads-up display for live crisis monitoring and data visualization.
*   **War Room Modules:** Comprehensive tools tailored for in-depth geopolitical and market analysis.
*   **Fast & Interactive:** Built with a modern Vite and Node.js stack for a highly responsive user experience.

## 🛠️ Tech Stack

*   **Languages:** JavaScript, TypeScript
*   **Build Tool:** Vite
*   **Package Manager:** Bun
*   **Deployment:** Vercel & Render

## ⚙️ Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and [Bun](https://bun.sh/) installed.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Spandan2106/Global-Crisis-Intelligence.git](https://github.com/Spandan2106/Global-Crisis-Intelligence.git)
    cd Global-Crisis-Intelligence
    ```

2.  **Install dependencies:**
    ```bash
    bun install
    ```

3.  **Set up environment variables:**
    Copy the example environment file and fill in your specific configurations.
    ```bash
    cp .env.example .env
    ```

4.  **Start the development server:**
    ```bash
    bun run dev
    ```
